Frequently asked questions

What is Markdown?
Markdown is a lightweight markup language that converts plain text with simple formatting symbols into formatted HTML. Created by John Gruber in 2004, it uses characters like # for headings, ** for bold, and - for list items. It's widely used for documentation, README files, blog posts, and note-taking.
How do I make a heading in Markdown?
Use the # symbol followed by a space and your heading text. One # = H1 (largest), ## = H2, ### = H3, up to six levels (######). Click the H1, H2, or H3 buttons in the toolbar above to insert a heading prefix on the current line.
How do I make bold and italic text in Markdown?
Wrap text in double asterisks for bold: **bold**. Wrap in single asterisks for italic: *italic*. Combine them for bold italic: ***bold italic***. Use the B and I buttons in the toolbar above to wrap your selected text automatically.
How do I create a code block in Markdown?
For inline code, wrap in backticks: `code`. For a fenced code block, wrap in three backticks on their own lines — optionally add a language name after the opening backticks for syntax highlighting: ```javascript. Click the </> button in the toolbar to insert a code fence.
How do I create a link in Markdown?
Use the format [link text](URL). Example: [Visit The Creating Co](https://thecreatingco.com). Click the 🔗 button in the toolbar and it will prompt you for the URL and insert the formatted link for you.
How do I create a table in Markdown?
Use pipes | to separate columns and hyphens --- to create the header separator. Example:
| Name | Age |
| --- | --- |
| Alice | 30 |
Align columns with colons: | :--- | for left, | :---: | for center, | ---: | for right.
What is CommonMark?
CommonMark is a standardized specification for Markdown that defines exactly how every construct should be rendered. The original Markdown had ambiguous edge cases, leading to different renderers behaving differently. This editor uses the marked.js library which follows CommonMark closely and supports GitHub Flavored Markdown (GFM) extensions like tables and strikethrough.

# How to use Pocket Starter Patterns

Pocket saves your patterns in your browser's local storage, not to an account, so there's no one-click "Open in Pocket" link yet — to load these eight starter grooves, open Pocket (https://sattarimusic.com/studio/pocket), open your browser's developer console (F12 on Windows/Linux, Cmd+Option+I on a Mac, then click the Console tab), paste the single line from `IMPORT-CONSOLE-COMMAND.txt` in this pack, and hit Enter; reload the page and all eight patterns will show up in Pocket's saved list, ready to load, tweak, and make yours. That command replaces your saved-patterns list outright, so if you already have patterns worth keeping, save or export them first. If you'd rather build the list yourself, each groove also ships as its own file in `patterns/` and together as `all-patterns.json` — the exact shape Pocket stores — so you can merge them in by hand or wire up your own importer later. Make a thing. Make some noise. Make it yours.

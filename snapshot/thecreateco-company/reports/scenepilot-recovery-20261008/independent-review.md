Synchronize each attempt with a completed IPC/UI transition and a changed disk revision (`savedAt` plus expected edited state), using bounded retry of parse/read; do not treat an already-visible status as completion. Parent reports this correction in progress.
2. **High: recovery equality is circular unless the journal is also checked against the pre-edit fixture.** Original journal assertion verifies only one added track, then recovered output is compared to that journal. Loss that occurred before journal creation can therefore pass both. Compare journal with the owned fixture across authored fields, allowing only the known added-track delta and explicitly documented normalization, then compare recovery with the journal.
3. **Medium: comparison skips serialized fields/media metadata.** Original comparison omits `format`, `version`, `sections`, `mainAsset`, `renderAnalysis`, `analysis`, and top-level intelligence/transcript/story fields; assets are reduced to id/name/kind, omitting source links, size/time, folders/favorites and beat maps. `proState` already covers autoPolicy/autoVersions and authored audio state. Compare all project-document keys except `savedAt`; explicitly normalize only expected differences (e.g. moved asset path, metadata differences from owned copies or linked main stubs). Key-by-id asset comparison is preferable to order dependence. Check bpm/beatOffset/beats in every stage, not only crash recovery. Parent reports broader comparison in progress.
4. **Medium: collected renderer errors do not affect PASS.** Require zero unexpected `pageerror`s; preserve any narrow documented allowlist rather than silently ignoring errors. Parent reports correction in progress.
5. **Medium: source declaration does not bind renderer provenance.** HEAD matches the hard-coded source, but main chooses inherited `SCENEPILOT_URL` or generated `electron/renderer/desktop/index.html`. Record launched URL, build provenance and source/runtime hashes (or reproducible build command); assert the expected isolated renderer. A matching git HEAD alone cannot establish that generated/served renderer matches it.
6. **Low: journal selection is lexical over full project-folder paths, not global journal timestamp.** Restrict discovery to the opened project folder and choose numeric timestamp newest, or inspect eligible entries and choose newest `savedAt`. In this one-project isolated run the current filter plus track-count check is probably sufficient, but it is fragile on reuse.

Successful cleanup detaches before removing its owned directory; a detach failure prevents deletion. Safe bounded pressure test; optionally assert mounted volume identity from `hdiutil attach -plist` and absence of `.partial` files after failed write.

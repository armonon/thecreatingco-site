# Retired public alpha downloads

The legacy Audio Suite installers and download page source were moved here from
`public/downloads/` and `src/pages/DownloadsPage.tsx`. This directory is outside
Netlify's `public/` input and `dist/` output. These builds remain in source
history for internal review; they are not a qualified release or an invitation
to republish them.

`SHA256SUMS.txt` records the moved files. The public `/downloads` path and its
legacy `/audio-suite` and `/audio` aliases must return 404. The current browser
music tools and shop remain available; no deployment is implied by this archive.

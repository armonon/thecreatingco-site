FROM DOWNLOAD TO FIRST FRAME

Make room
for your next idea.

No source-media upload is required for the core local workflow. Advanced models and acceleration depend on your system.

  1. 01

    Check the release.

    Open the release page and read the platform requirements and known issues. Download the Apple Silicon DMG; verify a checksum if the release supplies one.

  2. 02

    Install the desktop preview.

    Open the disk image and move ScenePilot to Applications. Follow the release’s installation guidance. Don’t disable macOS security protections.

  3. 03

    Bring a small test project.

    Import a song, footage or images. Make a short sequence, add a composition, save it and test an export before starting an important delivery.

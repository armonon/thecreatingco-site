# Third-party model provenance

ScenePilot Pro stages Apple’s Core ML conversion of Meta SAM2 Tiny from `apple/coreml-sam2-tiny`. The model, conversion, and upstream SAM2 code are Apache-2.0 licensed. Release staging verifies every package file by byte length and SHA-256 before it enters the desktop bundle.

The native selector uses SAM2 for promptable arbitrary-object masks. Its persistent Core ML process retains a bounded bank of up to five scored SAM2 image embeddings and display mattes per subject. The user's first selection is protected; later anchors are selected deterministically for temporal recency and diversity of position, area, and time. ScenePilot aggregates foreground and background neural prototypes from the bank, correlates them against the next frame’s embedding, and supplies the strongest spatially separated matches as learned memory prompts. This is ScenePilot multi-anchor feature-memory attention over Apple’s exported SAM2 image features; it is not Meta’s original SAM2 video-memory network, which is not included in Apple’s Core ML packages.

Universal soft-alpha refinement uses the official `hustvl/vitmatte-small-composition-1k` weights. The upstream ViTMatte implementation is MIT licensed and the published model is Apache-2.0 licensed. `scripts/convert-vitmatte-coreml.py` freezes the official network to verified 512×512 image and trimap inputs; the converted FP16 Core ML result was measured against PyTorch with maximum absolute error below 0.0004. Its files and MIT notice are distributed through the public `armonon/scenepilot-releases` model release and receive the same byte-length and SHA-256 checks before packaging.

Apple Vision supplies the learned person-alpha path. ScenePilot’s serializable appearance bank, deformable pixel flow, correction anchors, and fail-closed identity gates remain the project-safe recovery layer around the native neural service; Core ML model instances and embeddings never enter project files or render-worker messages.

MatAnyone was evaluated and deliberately excluded from the commercial build because its S-Lab 1.0 weights are limited to non-commercial use without separate permission.

ScenePilot Pro stages the Open Model Zoo `gmcnn-places2-tf` neural inpainting weights under the upstream MIT license. The model archive, extracted frozen graph, executable adapter, OpenVINO runtime files, and license notices are pinned and SHA-256 verified. OpenVINO 2026.3.1 is Apache-2.0 licensed and supplies native CPU inference on supported Apple Silicon, Windows, and Linux builds. The model runs in an Electron Node helper outside the renderer. ScenePilot first recovers each pixel from the temporally nearest frame where it is visible, preserving real captured pixels byte-for-byte, and sends only regions hidden across the entire sampled sequence to GMCNN. The neural result is feathered only into those unresolved regions.

The provider boundary still fails closed: requests have fixed frame, dimension, memory, output, and timeout limits; all helper/runtime/model artifacts are verified before launch; returned byte dimensions are validated; and temporary source frames are removed after each job. If staging is unavailable, verification fails, the provider crashes, or it returns malformed data, ScenePilot visibly falls back to the deterministic temporal clean-plate engine. `npm run qa:neural-inpaint-model` performs real inference with the packaged weights and records the exact executable and model digests.

ProPainter and E2FGVI were evaluated and deliberately excluded because their official code and model licenses are non-commercial. Netflix VOID is Apache-2.0 and remains a compatible future high-end provider candidate, but its official implementation currently requires a CUDA GPU with roughly 40 GB or more VRAM; it is not represented as the default desktop model.

## Film tools (alpha) — Captions speech-to-text

The browser Captions tool (`/tools/captions/`) and the editor's existing vocal-transcription beta share `app/transcribe.worker.ts`. It loads transformers.js 3.0.2 (Apache-2.0, Hugging Face) from the jsDelivr CDN at runtime, which runs ONNX Runtime Web (MIT, Microsoft) on WASM or, opt-in, WebGPU. The models are the transformers.js ONNX exports of OpenAI Whisper — `Xenova/whisper-tiny.en`, `Xenova/whisper-base.en` and `Xenova/whisper-tiny` — downloaded from the Hugging Face Hub on first use and cached by the browser. OpenAI published Whisper's code and weights under MIT; the Hugging Face model cards for `openai/whisper-*` and these Xenova conversions declare Apache-2.0. Both permit commercial use with attribution. Nothing is bundled into the repository or the desktop app, no audio leaves the device, and no API key is involved. Grade and Board use no models.

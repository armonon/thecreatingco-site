Color format reference

When to use each format in your code or design tool.

Format Example Best for
HEX #3b82f6 HTML, CSS, design tools (Figma, Sketch, Photoshop). The universal format.
RGB rgb(59, 130, 246) CSS and JavaScript. Useful when you need to manipulate individual channels or add opacity with rgba().
HSL hsl(217, 91%, 60%) CSS and design systems. The most human-readable format — easy to adjust lightness without changing the hue.
HSV hsv(217, 76%, 96%) Color picker UIs and image editing software. Not a native CSS format but common in design tools.
RGBA rgba(59, 130, 246, 0.8) CSS overlays, shadows, and any element where transparency is needed alongside a specific color.
HSLA hsla(217, 91%, 60%, 0.8) CSS with transparency, same benefits as HSL but with an alpha channel for opacity.

Frequently asked questions

How do I convert HEX to RGB?
Enter the HEX color code (e.g. #3b82f6) and the color picker instantly shows the equivalent RGB values (e.g. rgb(59, 130, 246)) alongside HSL and HSV. Click the RGB value to copy it directly to your clipboard.
What is the difference between HEX, RGB, and HSL?
HEX is a six-character code used in HTML and CSS (e.g. #ff6040). RGB defines a color by its red, green, and blue components, each from 0–255. HSL defines a color by hue (0–360°), saturation (0–100%), and lightness (0–100%) — HSL is often more intuitive for creating color variations because you can adjust lightness or saturation independently.
Can I use this to check color contrast for accessibility?
Yes — the color picker shows the WCAG 2.1 contrast ratio between any two colors you pick. A ratio of 4.5:1 or higher meets AA standard for normal-sized text; 3:1 meets AA for large text (18pt+ or 14pt bold); 7:1 meets the stricter AAA standard.
What are complementary colors?
Complementary colors sit opposite each other on the color wheel — 180° apart in hue. They create maximum contrast when placed side by side. The color picker shows the complementary color and also generates triadic (120° apart), analogous (30° apart), split-complementary, and tetradic schemes.
Can I pick a color from an image?
Yes — use the eyedropper tool to click any color on your screen. This uses the browser's native EyeDropper API, which is supported in Chrome, Edge, and Opera. You can also upload an image and click any pixel to sample its exact color value.
How do I get the CSS value for a color?
The color picker shows the color in all CSS formats simultaneously: hex (#3b82f6), rgb(59, 130, 246), hsl(217, 91%, 60%), and rgba() with an adjustable opacity slider. Click any format to copy it instantly to your clipboard.
What is HSV versus HSL?
Both describe colors using hue and saturation, but they differ in the third value. HSV (Hue, Saturation, Value) uses "value" for brightness — a value of 100% is the pure hue, and 0% is black. HSL (Hue, Saturation, Lightness) uses "lightness" — 50% lightness is the pure hue, 100% is white, and 0% is black. HSL is a native CSS format; HSV is not, but is common in design tools and color pickers.

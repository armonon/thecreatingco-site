Favicon sizes — what you need and why

Modern websites need more than a single favicon.ico. Here's the complete picture.

SizeFormatUsed for
16×16ICO / PNGBrowser tab (primary). The smallest favicon size — every browser reads it from favicon.ico.
32×32ICO / PNGBrowser tab on high-DPI displays, Windows taskbar pinned sites, and some browser bookmark views.
48×48ICOWindows Start menu and desktop shortcuts when your site is installed as a PWA on Windows.
64×64PNGHigher-resolution Windows taskbar icon. Also the Windows tile icon for Chromium-based browsers.
180×180PNGApple touch icon — shown on iOS and macOS home screen bookmarks. Requires a solid background colour; iOS doesn't show transparency.
192×192PNGAndroid home screen icon. Referenced in the web app manifest (manifest.webmanifest) as the standard Android PWA icon.
512×512PNGAndroid PWA splash screen and Chrome app shelf. Also used as the maskable icon when cropped to a safe zone.
Any sizeSVGThe most future-proof format — scales perfectly at any resolution and supports dark mode via prefers-color-scheme inside the SVG.

The HTML you need in <head>

Add these lines to your page's <head> element after generating your favicon package.

<!-- Browser tab icon (traditional, all browsers) --> <link rel="icon" href="/favicon.ico" sizes="any"> <!-- Modern SVG favicon (Chrome, Firefox, Edge) --> <link rel="icon" href="/favicon.svg" type="image/svg+xml"> <!-- Apple touch icon (iOS & macOS bookmark) --> <link rel="apple-touch-icon" href="/apple-touch-icon.png"> <!-- PWA web manifest (links to 192 and 512 icons) --> <link rel="manifest" href="/manifest.webmanifest">

Frequently asked questions

What is a favicon?
A favicon (favourite icon) is the small icon that appears in browser tabs, bookmarks, and on the home screen when someone saves your website as a shortcut. It's typically 16×16 or 32×32 pixels for browser tabs, 180×180 pixels for Apple devices, and 512×512 pixels for PWA splash screens.
What size should a favicon be?
Modern browsers need multiple sizes. The minimum is 16×16 and 32×32 for browser tabs. For Apple touch icons, 180×180 is the standard. For Android home screen icons and PWAs, 192×192 and 512×512 are required. The favicon generator creates all these sizes in one go so you don't have to do it manually.
What is the difference between favicon.ico and favicon.png?
favicon.ico is the traditional format that can embed multiple sizes (16×16, 32×32, 48×48) in a single file — older browsers and some tools only read .ico. favicon.png is a single-size file supported by all modern browsers. SVG favicons (favicon.svg) are the most future-proof as they scale perfectly at any size and support dark mode.
Do I need an SVG favicon?
SVG favicons are increasingly recommended because they scale perfectly at any resolution and support dark mode — you can change the icon appearance based on the user's colour scheme using prefers-color-scheme inside the SVG. They're supported by all modern browsers but not Internet Explorer. Use them alongside favicon.ico for the best coverage.
How do I add a favicon to my website?
Place favicon.ico in your website's root directory — browsers find it automatically without any HTML. For additional sizes, add link tags in your <head>: <link rel="icon" type="image/png" href="/favicon-32x32.png" sizes="32x32">, <link rel="apple-touch-icon" href="/apple-touch-icon.png">, and <link rel="icon" href="/favicon.svg" type="image/svg+xml">. The favicon generator includes a ready-to-paste HTML snippet with every download.
What image format should I start with?
Start with a high-resolution PNG (512×512 or larger) or an SVG for the best quality. The favicon generator will downsample it cleanly to all the smaller sizes. A square image with a transparent background works best for browser tabs. Avoid complex gradients at small sizes — they become muddy at 16×16 pixels.
Can I use a logo with a transparent background?
Yes — the favicon generator preserves transparency. Upload a PNG with an alpha channel and all generated PNGs retain the transparency. favicon.ico also supports transparency (from Windows Vista onward). For the Apple touch icon, a solid background is automatically added since iOS does not display transparency.

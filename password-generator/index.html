Password strength guide

Entropy in bits measures how hard a password is to crack. Each extra bit doubles the difficulty.

Very Weak (<40 bits)
Can be cracked instantly. 6-char lowercase only. Never use.
Weak (40–59 bits)
Crackable in hours–days with modern hardware. Not acceptable for any real account.
Fair (60–79 bits)
Resistant to casual attacks. Minimum for personal accounts. Could be cracked with dedicated resources.
Strong (80–99 bits)
Very resistant to brute force. Sufficient for most accounts. 16-char mixed password typically falls here.
Very Strong (100+ bits)
Essentially uncrackable with current technology. Ideal for password manager master passwords and banking.

Frequently asked questions

How do I create a strong password?
A strong password should be at least 16 characters long and include a mix of uppercase letters, lowercase letters, numbers, and symbols. It should not contain dictionary words, personal information, or common patterns. Using a password generator — like this one — is the easiest way to create a truly random, strong password.
Is it safe to use an online password generator?
This password generator is completely safe — it runs entirely in your browser using the Web Cryptography API (crypto.getRandomValues), which provides cryptographically secure randomness. No passwords are ever sent to any server or stored anywhere. You can verify this by disconnecting from the internet — the generator will still work perfectly.
How long should a password be?
Security experts recommend at least 12 characters, with 16 or more being significantly stronger. For highly sensitive accounts (email, banking, password manager master password), use 20+ characters. Password length has the biggest single impact on security — each additional character multiplies the number of possible combinations exponentially.
What is password entropy?
Entropy (measured in bits) is the mathematical measure of a password's unpredictability. Each bit doubles the number of possible passwords an attacker must try. A password with 80 bits of entropy has 2^80 (over a trillion trillion) possible combinations — far too many to brute-force with current technology. This generator shows entropy in the strength meter.
Should I use a password manager?
Yes — a password manager is the most effective security practice after using strong unique passwords. It stores all your passwords in an encrypted vault so you only need to remember one master password. This lets you use a different strong random password for every account, which is the most important thing you can do to protect yourself from data breaches.
What symbols are safe to use in passwords?
Most symbols are safe: ! @ # $ % ^ & * ( ) - _ = + [ ] { } ; : , . < > ? / ~ `. However, some websites restrict certain characters. If a site rejects your password, try regenerating without symbols or use a longer password with just letters and numbers — the extra length compensates for the reduced character set.
What is a passphrase?
A passphrase is a sequence of random words (e.g. correct-horse-battery-staple) rather than a string of random characters. Passphrases are easier to remember and very secure when they use 4+ truly random, unrelated words. For accounts managed by a password manager, a random character password of 20+ characters is equally strong.

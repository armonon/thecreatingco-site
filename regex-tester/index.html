Frequently asked questions

What is a regular expression (regex)?
A regular expression is a pattern that defines a search or match rule for text. It is built into virtually every programming language and many text editors. Common uses include validating email addresses, extracting phone numbers, parsing log files, and find-and-replace operations across many files at once.
What do the flags g, i, m, s, u mean?
g (global) — find all matches, not just the first. i (case-insensitive) — match regardless of letter case. m (multiline) — ^ and $ match line starts/ends, not just the whole string. s (dotAll) — the dot matches newlines too. u (unicode) — full Unicode support for emoji and non-ASCII patterns.
What is a capture group?
A capture group is a portion of the pattern wrapped in parentheses: (\w+). When the pattern matches, the text inside each group is captured and can be extracted independently. Group 0 is always the full match. Named groups use (?<name>pattern).
Why does my pattern match too much?
Greedy quantifiers (*, +) match as much text as possible. Add ? to make them lazy: .*? matches as little as possible. Also check that you're using word boundaries (\b) when needed — without them, \d+ matches digits inside longer words.
How do I match a dot, parenthesis, or other special character literally?
Escape it with a backslash: \. matches a literal dot (not any character). The special characters that need escaping are: . * + ? ^ $ { } [ ] | ( ) \. Inside a character class [...] most of these lose their special meaning.
Does this tester use JavaScript regex syntax?
Yes. This tester uses the browser's built-in RegExp engine, which is JavaScript's regex engine. JavaScript regex is very similar to Perl, Python, Ruby, and other languages, but there are some minor differences — for example, JavaScript does not support lookbehind assertions in older browsers (though modern browsers support them via the ECMAScript 2018+ spec).
How do I match a whole line that contains a word?
Enable the m (multiline) flag, then use ^.*word.*$. The ^ matches the start of the line and $ matches the end. The .* on each side matches any characters before and after the word on that line.

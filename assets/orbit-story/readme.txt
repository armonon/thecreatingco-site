ORBIT / ONE PROJECT, FOUR CREATIVE ACTS

Form: orbit-pendant.form is the existing exact CAD study, 32 x 2.4 mm. The JPG is a Blender render of Form's exact tessellation, not a photograph or a Form screenshot. The STEP is interchange, not manufacturing qualification.
Luma: orbit-artwork.luma was prepared and round-trip verified using Luma's native engine. It has editable type, shapes, image layers and two artboards. Its PNG files are actual native-engine renders.
StemDeck: orbit-sound.sattari and orbit-sound.wav were saved/exported from the real Sattari-based arrangement workshop. The WAV is stereo 48 kHz, 24-bit; the project embeds five audio assets and includes a drum break.
ScenePilot: orbit-film.scenepilot.json is an editable cut map in the native v2 format. Import/relink the three matching MP4 files and orbit-sound.wav. The cut JSON does not embed source media.
Preview: orbit-preview.mp4 was assembled with FFmpeg from these source clips and the genuine StemDeck mix. It is a reference preview, NOT a claimed ScenePilot export.
Handoffs are portable files, not live synchronization between apps.

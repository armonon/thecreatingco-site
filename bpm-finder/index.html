How to use the BPM & Key Finder

  1. Open Key & BPM

    Go to sattarimusic.com/studio/keybpm. The tool runs in your browser — no install required.

  2. Upload your audio file

    Drag a WAV, MP3 or FLAC onto the drop zone, or click to browse. For batch mode, load several files at once.

  3. Read the results

    The tool displays BPM with a confidence label (supported / rough estimate) and the detected musical key. A blank key means inconclusive — not that the track is atonal.

  4. Export a CSV

    If you analysed multiple files, download the CSV to keep a record with filenames, BPM and key for each. Import into a spreadsheet or use it to plan a mix.

Common questions

What audio formats does the BPM finder support?

Key & BPM accepts WAV, MP3, FLAC and other common browser-decodable audio formats. Analysis runs client-side — nothing is sent to a server.

Why does my BPM result show half or double my expected tempo?

A tempo algorithm detects a periodic pulse, not a named musical beat. A 120 BPM track also has a 60 BPM half-note pulse and a 240 BPM sixteenth-note pulse. The tool reports the strongest detected period. Choose the multiple that aligns with your grid — read the full explanation here.

How accurate is the key detection?

Key estimation works best on tracks with clear, sustained harmonic content. Percussion-heavy or atonal audio, very short clips, or heavily compressed masters may return an inconclusive result. When the tool returns a blank key, it means it didn't find sufficient evidence — not that it failed.

Can I analyse multiple files at once?

Yes. Key & BPM supports batch mode — load several files and compare their tempo and key estimates side by side, then export the full set as a CSV.

Is my audio uploaded to a server?

No. The entire analysis runs in your browser. Your audio files never leave your device.

What's the difference between a supported BPM and a rough estimate?

"Supported" means the algorithm found a clear, consistent pulse that passed internal thresholds. "Rough estimate" means it detected a likely period but with lower confidence — worth cross-checking by ear or with a tap-tempo tool.

Frequently asked questions

What is a CSS gradient?
A CSS gradient is a type of image created using the CSS functions linear-gradient() or radial-gradient(). They transition smoothly between two or more colors without using an image file. Gradients are used for backgrounds, buttons, overlays, and decorative elements in web design.
What is the difference between linear and radial gradients?
A linear-gradient transitions colors along a straight line at a specified angle. A radial-gradient transitions colors outward from a center point in a circular or elliptical pattern. Linear gradients suit banners and backgrounds; radial gradients work well for glows and spotlights.
How do I use a CSS gradient as a background?
Use the background or background-image property and pass the gradient function as the value. Example: background: linear-gradient(135deg, #667eea 0%, #764ba2 100%). The "Copy background" button above outputs this format directly.
Can I add more than two colors to a CSS gradient?
Yes — you can add as many color stops as you like using the "+ Add stop" button. Each color stop is a color value at a position (percentage). This creates multi-color transitions like linear-gradient(90deg, red 0%, orange 33%, yellow 66%, green 100%).
What does the gradient angle mean?
The angle controls the direction a linear gradient flows. 0° runs bottom to top, 90° left to right, 180° top to bottom, and 270° right to left. Angles between these create diagonal gradients. The angle slider updates the preview in real time.
How do I make a transparent gradient in CSS?
Use rgba() or the transparent keyword. For example: linear-gradient(to right, rgba(0,0,0,0.8), transparent). This creates an overlay that fades from semi-transparent black to fully transparent — great for text overlays on images.
Does CSS gradient work in all browsers?
Yes — linear-gradient and radial-gradient are supported in all modern browsers: Chrome, Firefox, Safari, Edge, and Opera. They've been widely supported since 2012. No vendor prefixes are needed for current browsers. The CSS output from this generator uses standard unprefixed syntax.

Orbit.

01 / Form

Give an idea a shape.

Start with the Orbit pendant: a sculpted ring with a 32 mm outer diameter. The exact Form geometry becomes the visual thread for the whole campaign.

32 mm diameter / 2.4 mm depth / Exact CAD study

02 / Luma

Turn an object into an identity.

Bring the pendant render into Luma. Layer editable type and graphic shapes around it, then make a launch poster and a square release image in the same document.

13 editable layers / 2 artboards / 2400 × 1500 document
Luma project / 415 KBPoster PNG / 263 KBSquare PNG / 238 KB

03 / StemDeck

Give the reveal a rhythm.

Take four prepared stems into the real Sattari-based StemDeck arrangement workspace. Three phrases and a brief drum break give the visual reveal an opening, a drop and a return.

126 BPM / 4 tracks / 48 kHz · 24-bit WAV
StemDeck session / 19.3 MBMixdown WAV / 6.3 MB

04 / ScenePilot

Bring the whole world together.

Object, poster, release image. Match three visual clips to the StemDeck soundtrack in a 23-second cut. Download the ScenePilot cut map together with every source you need to keep shaping it.

3 source clips / 23-second reference film / Native v2 cut map

Import the cut JSON and relink the three MP4s and WAV from the ZIP. This reference preview was assembled with FFmpeg, not exported by ScenePilot.

Your turn to take it further.

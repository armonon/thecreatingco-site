AFTER HOURS / Reclaim / File review · read-only

Find the copies worth reviewing.

An exhibition folder contains working files, exports, backups, and two notes with the same name. Compare their actual content before making a decision.

See the selected set

Seven original demonstration files total about 6.3 MB. The review lists their names and sizes and finds two groups of identical content.

Match the bytes

A PDF pair and an audio pair match despite their different filenames. Together, the extra copies account for 3,277,228 bytes; no files were deleted.

Narrow the review

Searching Field-Notes isolates the working PDF and its final-copy counterpart while preserving the full review.

Keep the evidence

Two 67-byte notes.txt files have different contents and are not grouped as duplicates. The downloaded JSON report records the comparison results.

Download the actual review report

YOUR BROWSER EDITION

Your web edition.

Inspect files you select, find identical copies by content, sort large files, and export a review report.

Current limitations

This read-only browser companion cannot scan your whole Mac, clear caches, quarantine or delete files. It is a scoped testing experience for file review, not the native cleanup engine.

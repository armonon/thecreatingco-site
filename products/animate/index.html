Frame-by-Frame & Tween Animation

Animate · alpha

Frame-by-Frame & Tween Animation

Explore motion with frame-by-frame drawing and tween animation. Animate is a focused browser workspace for developing an animation idea.

A practical starting workflow

  1. Open the animation studio and start a small study
  2. Compare frame-by-frame changes with a tweened movement
  3. Preview the motion and review the available save or export controls

Before you rely on it

This is a public alpha. Confirm the save and export behavior in the current workspace before building a long production.

Declared input types: Start in the workspace; this catalog does not declare file import types.

Declared inputs describe expected formats, not certified decoder coverage. Save a separate copy of important work.

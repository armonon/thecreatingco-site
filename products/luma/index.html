Your web edition.

Current limitations

Native RAW codecs and desktop print features are not all available in the browser. Optional hosted generative edits require sign-in and send selected image content to a service. PSD conversions have limits.

NEW IN LUMA STUDIO

Mockup and Glyph, in the “…” menu.

Both are public web alpha, inside the same Luma Studio you already use.

Mockup

Put your art onto a tee, hoodie, tote, poster, vinyl sleeve, or phone case, then batch-export every scene as PNG or JPEG. Scenes are procedural illustrations, not photographed products. Open Luma Studio, then use the “…” menu → Mockups. Open Luma Studio ↗ · More about Mockup

Glyph

Draw your own letterforms with brush or pen tools and export OTF/TTF. Installed fonts now embed in .luma projects so they reopen anywhere, and the font shows up directly in Luma’s type tool. Open Luma Studio, then use the “…” menu → Glyph font maker. Open Luma Studio ↗ · More about Glyph

Cutout: Background Removal & Transparent Images

Luma · alpha

Layered Image Editor

Build an image with layers, selections, masks and type. Luma lets you keep creative edits together in a browser workspace.

A practical starting workflow

  1. Open an image or start a document
  2. Arrange layers and refine selections, masks or lettering
  3. Keep an editable copy and inspect the exported image

Before you rely on it

Public alpha behavior and format support vary. Keep your original files and check the result before delivery.

Declared input types: image/png, image/jpeg, image/webp, image/gif, image/svg+xml, .luma, font/otf, font/ttf, .otf, .ttf

Declared inputs describe expected formats, not certified decoder coverage. Save a separate copy of important work.

How to check an image export against its editable layers

A flattened picture and an editable document solve different problems. Before closing an image editor, make sure you can keep editing and that the exported image matches the intended layer state.

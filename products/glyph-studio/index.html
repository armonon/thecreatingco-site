Glyph Studio

Draw your own font, right in the browser.

Glyph Studio is a standalone draw-your-own-font tool, spun out of Luma Studio's Glyph feature into its own app with a decoupled engine. Brush and pen drawing, smooth curve fitting, a kerning-pairs editor, metrics, a type tester, and OTF/TTF export, with an Open in Luma link.

Open Glyph StudioSee how it works

Web studio · drawn letterforms, not a font-engineering tool

Public alpha · Availability & current scope · Send feedback

WHAT IT DOES

Draw letterforms, export a working font.

Draw each glyph with a brush or pen, and Glyph Studio fits a smooth curve to your strokes. Set up kerning pairs and check metrics, then try the result in the built-in type tester. Projects save and load as .glyph files, with autosave to this browser's storage, and the finished font exports as OTF or TTF — or opens directly back in Luma Studio's type tool.

HOW IT WORKS

Three steps to a working font.

  1. 01

    Draw your glyphs.

    Use the brush or pen tool to draw each letterform; curves are fit automatically.

  2. 02

    Set kerning and check metrics.

    Adjust spacing between letter pairs and try the result in the type tester.

  3. 03

    Export or send to Luma.

    Export OTF/TTF, or open the font directly in Luma Studio's type tool.

HONEST LIMITS

What Glyph Studio doesn't do.

Current limitations

Kerning currently exports to TTF only, not OTF — the underlying library (opentype.js) has no GPOS/kern table writer yet. This is a public web alpha; projects autosave to this browser's storage, which is not an account backup, so keep an exported copy of work you want to keep.

One good first test

  1. 01Draw a few letters with the pen tool.
  2. 02Adjust kerning between two letters.
  3. 03Export TTF and try it in the type tester.

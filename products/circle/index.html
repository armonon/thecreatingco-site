The Circle · alpha

Creative Community & Project Sharing

Meet creative people through profiles, projects, collections and discussions. The Circle connects the suite’s shared community workflows.

A practical starting workflow

  1. Explore the public network and creative projects
  2. Sign in when a contribution or account feature requires it
  3. Review visibility before sharing a project or joining a discussion

Before you rely on it

Community features are in public alpha. Review privacy and sharing settings; a profile or collection is not a backup for original project files.

Declared input types: Start in the workspace; this catalog does not declare file import types.

Declared inputs describe expected formats, not certified decoder coverage. Save a separate copy of important work.

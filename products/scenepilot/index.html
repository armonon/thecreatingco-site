AFTER HOURS / PROJECT WALKTHROUGH

Captured in ScenePilot · Browser Lite

An evening, in eighteen seconds.

See how artwork, a jacket study and a Form clasp become an editable 18-second exhibition trailer, set to a StemDeck soundtrack.

  • 3 source clips
  • 18 seconds editable timeline
  • StemDeck soundtrack

Follow the edit. Choose a step to see what changed in the real workspace.

Editor screenshots · 4 steps

STEP 1 / 4

Import the sources

Start with three short clips: artwork made for Luma, a jacket reference from Ghost, and a clasp rendered in Form. Add the 18-second StemDeck mix as the soundtrack.

STEP 2 / 4

Build the first cut

Let Cinematic mode analyze the soundtrack and suggest an arrangement. This project creates ten main cuts and five overlays. Every shot stays editable.

STEP 3 / 4

Add soft transitions

Replace the incoming Zoom transition with a 0.30-second Dissolve, then apply it across the main cuts. The scenes blend gently as each new shot arrives.

STEP 4 / 4

Save and reopen

Save the project, then restore it in the same browser. The three source clips, soundtrack, 15 timeline items and effects return together. Export the cut file to keep the edit instructions.

KEEP MAKING

The complete ZIP includes the editable cut, three MP4 source clips and the soundtrack. The cut file stores your editing choices; the media files supply the picture and sound.

NEW IN SCENEPILOT

Four new tools alongside the editor.

All four are public web alpha, open straight from your browser.

AutoCut

A dedicated auto-editor for videos and music videos: beat- and energy-driven cuts, presets, multi-take lip-sync alignment, and 9:16 / 1:1 / 16:9 export. Opens into the main ScenePilot editor for further changes. Open AutoCut ↗ · More about AutoCut

Captions

On-device speech-to-text with animated caption styles. Burn captions into a WebM export, or take the SRT/VTT file elsewhere. Open Captions ↗ · More about Captions

Board

Turn a script into a shot list and storyboard, with PDF/CSV export and timeline markers you can carry into the edit. Open Board ↗ · More about Board

Grade

Pick a reference still and pull a color grade from it, then export a .cube LUT for use elsewhere. Open Grade ↗ · More about Grade

ScenePilot · alpha

Beat-Aware Browser Video Editor

Shape footage around timing and sound. ScenePilot combines a video timeline with beat-aware cutting and visual refinement.

A practical starting workflow

  1. Bring footage and audio into a project
  2. Arrange shots and review timing, transitions and color
  3. Watch the sequence and check the available export path

Before you rely on it

The web edition is an alpha. Test your actual media and browser before relying on a delivery workflow.

Declared input types: video/*, audio/*, image/png, image/jpeg, image/webp, .cube, .srt, .vtt, text/vtt

Declared inputs describe expected formats, not certified decoder coverage. Save a separate copy of important work.

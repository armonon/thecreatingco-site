Website Links, Metadata & Forms Check

Review a website’s links, metadata and forms before sharing it. Website Checkup is a focused inspection tool, separate from WebLab’s page builder.

A practical starting workflow

  1. Open Website Checkup and review its current inspection controls
  2. Choose the website or material supported by the tool
  3. Check the findings against the live site and repeat important user journeys

Before you rely on it

The checker remains a public alpha with a dedicated hosted preview backend. A check is not a complete accessibility, security or SEO certification.

Declared input types: Start in the workspace; this catalog does not declare file import types.

Declared inputs describe expected formats, not certified decoder coverage. Save a separate copy of important work.

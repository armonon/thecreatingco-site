A GOOD PLACE TO BEGIN

One tool. Three starting points.

1 / 3

An exhibition wordmark

Start with the letters needed for one short title.

  1. Open Glyph font maker from Luma's studio menu.
  2. Draw a few letters with a consistent baseline and cap height.
  3. Install the font in Luma, then build a title with the Type tool.

A handmade alphabet

Explore a shared stroke style across several characters.

  1. Choose a brush or pen and draw a small set of related letters.
  2. Preview a word and revise inconsistent widths or proportions.
  3. Export OTF or TTF to keep a copy outside the browser.

Numbers for a poster

Make a small display set for dates or edition numbers.

  1. Draw the numerals needed for your design.
  2. Check how they align against the same guides and metrics.
  3. Use the installed font on a text layer and save the font separately.

What should I know before starting?

This embedded Glyph has no curve fitting, hinting, kerning, accents or bold/italic styles. Undrawn characters fall back to another font. Installing a font here does not embed it into .luma or PSD files.

How do I keep my work?

Export the font as well as your artwork. A browser-installed font is local to that browser and is not an account backup.

Can I download a native app?

This page opens the public web alpha. There are no public native downloads yet. Check current availability.

How is this different from Glyph Studio?

Glyph is the simpler font maker inside Luma. Standalone Glyph Studio adds curve fitting and kerning; kerning exports to TTF only.

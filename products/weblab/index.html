WebLab

A page of your own. Code you can keep.

Shape a single web page with visual blocks, edit its words and colors, and inspect the HTML and CSS behind it.

Open WebLab ↗Current scope

Early prototype. No autosave or project reopening. Keep a copy of your generated code before leaving.

Build with blocks.

Combine a hero, headings, text, buttons, image placeholders and cards.

Make it yours.

Edit the text, background color and alignment of each block. Compare desktop, tablet and phone canvas widths.

See the code.

Inspect the generated HTML and CSS. The prototype includes an HTML export control; it does not publish or host your page.

Where we are today

A small beginning, openly shared.

WebLab is a visual website-building experiment, not a finished replacement for a production website builder.

  • One page at a time. No multipage projects, saved-project recovery or code import.
  • Image blocks are placeholders; image uploads are not available.
  • No automatic publishing, custom-domain connection or Locker handoff.
  • Editing and generated code have been checked. Download completion and physical-device behavior still need qualification.

This is the visual builder, separate from the experimental website-checkup tool also named WebLab.

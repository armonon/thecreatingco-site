Frequently asked questions

How do I set a countdown timer?
Use the hours, minutes, and seconds inputs to enter your desired time, or click one of the quick preset buttons (1 min, 5 min, 10 min, 25 min Pomodoro, etc.). Then click Start. The timer counts down and plays an alarm when it reaches zero.
Does the timer work in the background?
Yes — the timer continues counting even if you switch to another tab. The alarm plays when it finishes. Keep the browser window open; closing the tab or refreshing the page resets the timer.
Is there an alarm when the countdown ends?
Yes — the timer plays a short beep using the Web Audio API when the countdown reaches zero. Ensure your device volume is not muted. On iOS, tap Start at least once to allow the browser to play audio.
How do I use the stopwatch?
Click the Stopwatch tab at the top. Press Start to begin counting up. Press Lap to record a split time while the stopwatch continues running. Press Reset to clear all laps and return to zero.
Can I set a timer for more than an hour?
Yes — the hours field accepts values from 0 to 99, allowing timers up to 99 hours, 59 minutes, and 59 seconds. For very long timers, note that the browser tab must remain open.
What is a Pomodoro timer?
The Pomodoro Technique is a time-management method where you work for 25 minutes, then take a 5-minute break — one cycle is called a "Pomodoro." Use the 25 min preset, start working, then when the alarm sounds take a short break before starting the next session.
Does this timer work on mobile?
Yes — the timer works on any modern smartphone or tablet browser. The layout adapts to smaller screens. Note that iOS may require a tap interaction before audio can play — press Start at least once to enable the alarm sound.

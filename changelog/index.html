UPDATES & IMPROVEMENTS

What's new

New tools, improvements and fixes across the Creative Suite — Form, Luma, ScenePilot, StemDeck, Bounce, Glyph, Librarian, Reclaim and more.

Oct 18, 2026 New

Glyph Studio — Error recovery & keyboard shortcuts

Two quality-of-life additions to Glyph Studio: an error boundary that catches unexpected render crashes and shows a recovery screen (with an option to clear your autosave and start fresh), and a keyboard shortcuts panel you can open with ? or the ⌨ button.

  • Error boundary — no more blank screen if something goes wrong mid-session
  • Shortcuts panel — covers all 10 shortcuts: tools, navigation, undo/redo, pen modes
  • Accessibility — skip link on product-try pages, scope="col" on table headers
Glyph Studio
Oct 18, 2026 Perf

JS caching — 6 shared scripts now content-hashed

Six JavaScript files shared across nearly every page now have content-hash fingerprints in their filenames and a one-year Cache-Control: immutable header. Return visitors load them instantly from the browser cache.

  • momentium.js, site-navigation.js, audit-fixes.js, site.js, momentium-motion.js, start/motion.js
  • 103 HTML pages updated to reference the hashed filenames
  • Cache rules added to Netlify _headers
Site-wide
Oct 18, 2026 Security

Hardened response headers

Permissions-Policy now blocks the Payment Request API (payment=()). Immutable cache headers extended to JS bundles and image assets. Other minor header improvements via Netlify _headers.

Site-wide
Oct 18, 2026 SEO

Social share & SEO overhaul

A multi-run sweep of metadata across all 116 pages:

  • OG images — all indexed pages now have og:image for rich social previews
  • Twitter Cards — 74 pages upgraded to summary_large_image with image, title and description
  • Titles — 41 page titles shortened to ≤ 60 chars so they display fully in Google SERPs
  • JSON-LD — structured data added to Locker and Workspace product pages
  • Canonicals & descriptions — missing or incorrect tags corrected across product pages
  • Sitemap — expanded to 101 indexed URLs
Site-wide
Oct 18, 2026 Perf

CSS bundle — 14 global stylesheets consolidated

14 shared stylesheet <link> tags (~78 KB) that appeared on nearly every page have been merged into a single content-hashed file. Homepage: 23 → 14 CSS requests. Styles are visually identical.

Site-wide
Oct 18, 2026 A11y

Accessibility — skip links & table headers

Skip-to-content links added to 4 product-try pages (Bounce, Ghost, Libraria, Orbit). scope="col" attribute added to 22 table header cells across comparison and feature tables (WCAG 1.3.1).

Sep 29, 2026 New

Reclaim 0.1.1 for Mac — public alpha

Reclaim is now available as a signed and notarized Mac download. Review storage, quarantine selected items and restore what you keep. Automatic permanent deletion is off unless you explicitly enable it.

  • Universal binary — Apple Silicon and Intel
  • macOS 13 or later · 13.0 MB · Developer ID signed and notarized
  • Free to download; no account required

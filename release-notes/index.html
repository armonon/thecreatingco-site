Reclaim for Mac.

Review storage, quarantine selected items and restore what you keep. Automatic permanent deletion is off unless you explicitly enable it.

Version 0.1.1 · macOS 13 or later · Apple Silicon + Intel · 13.0 MB

Download for MacTry the read-only web preview

Developer ID signed and Apple-notarized. Free to download; no account required.

Install, safety & release details
  1. Open the downloaded DMG.
  2. Drag Reclaim into Applications, then open it there.
  3. Start with disposable files and check restore. Keep a current backup.

This is an alpha, not a fully qualified stable release. Clean-machine, physical Intel and oldest-macOS testing remain outstanding. Review each cleanup selection. Emptying quarantine permanently deletes its contents.

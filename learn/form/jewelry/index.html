Download the .form file, then choose Open project in Form. DXF keeps editable 2D circles; STEP keeps the CAD solid; STL is a triangle mesh. This is a design study—confirm fit, finishing and production details before making a physical piece.

CONTINUE IN FORM

The same project. Inside the real app.

Rebuild the sketch in Form

Use these commands one at a time in Form’s CAD command field. Coordinates and diameters follow the selected size.

circle diameter 32 mm at 0, 0
circle diameter 7.68 mm at 0, 15.68
circle diameter 17.92 mm at 2.4, 0
circle diameter 3.328 mm at 0, 15.68
  1. Choose millimeters and the World XY sketch plane.
  2. Create the four circles. Keep the outline and loop on one layer; place the window and chain opening on a cutout layer.
  3. Extrude all four profiles to the selected depth.
  4. Select the outline and outer loop bodies and use Fuse.
  5. Select the joined blank first, then the window and chain tool bodies. Use Cut.
  6. Inspect the result from the front and side. Save the .form project before exporting the CAD solid.

Glyph (in Luma) · alpha · worked example

A baseline worksheet for experimental lettering in Luma

Experimental lettering needs consistent guides before a full alphabet. Start with a few simple shapes and distinguish a drawn character from fallback text.

Updated October 10, 2026 · by thecreatingco

Open Glyph (in Luma)App overview & limits

Luma studio menu > Glyph.

A small example to work through

Our original test set is H, I and O, with a baseline of 0 and a cap-height guide of 700 arbitrary design units. These are planning coordinates, not measurements of an exported font.

Download the editable text worksheet · Download the CSV worksheet

Use the blank observation and decision fields to record your own result. These downloads are planning worksheets; they do not load an app project or demonstrate a completed export.

Try it and inspect the result

  1. Open Luma, then choose Glyph from its studio menu. Draw a small set against the baseline and height guides.
  2. Compare stem weight and spacing before compiling more characters. Use a short string that includes every drawn character.
  3. Try available OTF or TTF compilation and inspect the result in Luma. Check which characters are actually present rather than assuming a fallback letter belongs to your font.

When the result differs

Undrawn letter appears
It may be fallback; verify character coverage.
Round letter seems shorter
Judge optical size alongside numeric guides.
Need refined curves or kerning
This embedded experiment lacks curve fitting, hinting, kerning and full accented families.

What this example establishes

This is the embedded Luma Glyph experience, distinct from standalone Glyph Studio. The downloadable guide coordinates are not an importable project or an exported font. Use the standalone font guide for a real A-only TTF test.

This page supplies a worked example and a review method. It does not report a newly completed end-to-end app test. For current availability and edition details, read the Glyph (in Luma) overview.

How to check 3D model scale before sharing a mesh

A mesh can look correct on screen and arrive at the wrong size in another editor. Use a known dimension and a simple measurement record to distinguish a unit mismatch from a modelling mistake.

Updated October 10, 2026 · by thecreatingco

Open FormApp overview & limits

A small example to work through

Our original planning example is a rectangular display block intended to measure 100 × 50 × 20 mm. This is a dimension worksheet, not a Form export or a manufactured part.

Use the blank observation and decision fields to record your own result. These downloads are planning worksheets; they do not load an app project or demonstrate a completed export.

Try it and inspect the result

  1. In Form make a small object with one deliberately known edge. Keep a note of the intended units outside the project.
  2. Export through the current workspace controls. Retain the editable project and the original export separately.
  3. Open the file in its destination and measure all three axes. If every axis is 1000 times smaller, investigate units before stretching individual vertices.

When the result differs

All axes differ by the same factor
Check unit conventions and apply one uniform scale conversion.
Only one axis differs
Check transforms and your geometry; a unit conversion should not distort the shape.
The preview looks fine
Perspective and camera zoom hide scale errors. Use a numeric measurement.

What this example establishes

For this example, a measured 0.1 metres equals 100 mm. A measured 0.1 mm fails the intended size. A visual preview cannot establish tolerances, structural performance or fabrication readiness.

This page supplies a worked example and a review method. It does not report a newly completed end-to-end app test. For current availability and edition details, read the Form overview.
